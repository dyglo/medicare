# Medicare— Intelligent Hospital Prototype (React Native + Expo Go)

## Quick Start in VS Code
1. Open this folder in **VS Code**.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Expo development server:
   ```bash
   npx expo start
   ```
4. Scan the QR code with the **Expo Go** app on iOS or Android (or press `w` to open in web).
